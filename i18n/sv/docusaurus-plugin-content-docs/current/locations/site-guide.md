# Platsguide

Denna guide beskriver vad du kan förvänta dig på en typisk Stroomlijnen-laddplats och hur du hittar dig fram.

## Ankomst till en Plats

### Vägvisning
Titta efter de blå Stroomlijnen-skyltarna vid ingången. EL-vagnsplatser är märkta med:
- Golvmarkering (blå linjer eller målade EL-symboler)
- Platsnummerskyltar (överensstämmer med EVSE-ID i appen)
- Riktningspilar för genomfartsplatser

### Parkeringsplatser
- **Lastbilsplatser** är tydligt separerade från personbilsparkeringsplatser
- Genomfartslayout där möjligt — ingen backning behövs
- Om platsen har en bom eller grind, använd din RFID-bricka eller app för att komma in

## Laddutrustning

### DC-snabbladdare
Vår primära laddare för företagsfordon:
- **Effekt:** 150 kW – 400 kW per kontakt
- **Kontakt:** CCS Combo 2 (europeisk standard)
- **Kabel:** Vätskekyld, 5m+ räckvidd
- **Display:** Pekskärm med sessionsstatus, effekt, energi, SoC

### Hur man Ansluter

1. **Parkeringsplats** i den angivna EL-vagnsplatsen, förarsidan mot laddaren
2. **Öppna** CCS-laddluckan på fordonet
3. **Lyft** ut CCS-kontakten från laddarens hållare
4. **Anslut** fast CCS-kontakten i fordonets CCS-anslutning tills du hör/känner ett klick
5. **Autentisera** — PnC startar automatiskt; för RFID, knacka på din bricka på läsaren; för appen, skanna QR-koden
6. **Vänta** tills laddarens display visar "Laddar..." med ökande kW

### Koppla Loss

1. **Stoppa** sessionen — knacka på RFID-brickan igen, tryck på Stopp i appen eller använd stoppknappen på laddaren
2. **Vänta** tills laddaren bekräftar att sessionen har avslutats och kontakten är låst
3. **Ta bort** CCS-kontakten och häng tillbaka dem i hållaren
4. **Stäng** laddluckan på fordonet
5. **Lämna** platsen så att den är fri för andra fordon

:::caution
Tvinga aldrig CCS-kontakten medan sessionen är aktiv. Kontakten låses under laddning för säkerhets skull. Stoppa alltid sessionen först.
:::

## Säkerhetsinformation

- **Nödstopp** — Röd knapp på varje laddare, stänger av strömmen direkt
- **Brandbekämpningsutrustning** — Finns på varje plats, lämplig för elektriska bränder
- **Larmnummer** — Angivet på varje laddare, plus standard 112
- **Rökförbud** — Hela laddområdet är ett rökfritt område
- **Stanna i fordonet eller vänturum** under åska

### Kabelsäkerhet
- Ladda inte med en synligt skadad kabel — rapportera via appen eller ring support
- Håll laddområdet fritt från fallrisker
- Kör inte över laddkablar

## Faciliteter för Förare

Faciliteter varierar beroende på platsens typ:

### Teaterplatser
- Café eller restaurang ofta på platsen eller inom gångavstånd
- Offentligt WiFi tillgängligt på de flesta teaterplatser
- Offentliga toaletter under teaterns öppettider

### Logistiska Nav
- Vänterum för förare med sittplatser
- Toaletter
- Automater eller matställen i närheten

### Alla Platser
- Gratis WiFi (nätverk: "Stroomlijnen-Guest")
- Överbyggd gångväg där möjligt
- 24/7 bra belysning

## Rapportera Problem

Om det finns något problem på en plats:
- **Laddarfel** — Rapportera via appen (Hjälp → Rapportera problem) eller ring supportnumret på laddaren
- **Säkerhetsproblem** — Använd nödstoppknappen om det är brådskande, ring sedan support
- **Rengöring/tillgänglighet** — Rapportera via appen
- **Förbättringsförslag** — E-post [feedback@stroomlijnen.nl](mailto:feedback@stroomlijnen.nl)
