# Bidrag för laddinfrastruktur

Det finns flera bidragsprogram som kan finansiera inköp och installation av laddinfrastruktur. Här är en faktisk översikt.

:::warning
Bidragsprogrammen ändras regelbundet och kan ta slut. Kontroller alltid den senaste informationen på [rvo.nl](https://www.rvo.nl) innan du skickar in en ansökan. Skicka alltid in en ansökan **innan** du ådrar dig kostnader eller ingår avtal — detta är ett krav för de flesta programmen.
:::

## SPRILA

**Bidrag för offentlig laddinfrastruktur**

SPRILA-programmet från RVO bidrar till inköp och installation av offentligt tillgänglig laddinfrastruktur för tung vägtransport (lastbilar, bussar).

| Aspekt | Detaljer |
|---|---|
| **För vem** | Ägare av platser som vill installera offentligt tillgängliga DC-laddstationer för tung transport |
| **Vad som ersätts** | Hårdvara (laddstolpe) + installationskostnader |
| **Bidragsprocent** | Beroende på typ av sökande och plats |
| **Ansökan via** | [rvo.nl/subsidies-financiering/sprila](https://www.rvo.nl/subsidies-financiering/sprila) |
| **E-legitimation behövs** | Ja, nivå 3 |
| **Ansökan före investering** | Obligatorisk |

**Villkor (indicativ — kontroller alltid rvo.nl för aktuella villkor):**
- Laddstationen måste vara offentligt tillgänglig (eller tillgänglig för specifika målgrupper)
- Minst DC-laddstation (AC-laddare omfattas inte av programmet)
- Plats i Nederländerna

## SDE++ (för energiproduktion)

**SDE++** (Stimulering Duurzame Energieproductie och Klimattransitie) är ett produktionsincitament för hållbar energiproduktion. Relevant om du, utöver laddstationer, också:
- Installerar solpaneler
- Kombinerar batterilagring med egen produktion

SDE++ är inte ett direkt bidrag för laddstationer, men kan förbättra affärsfallet om du matar dina laddstationer med egen grön produktion.

Mer information: [rvo.nl/subsidies-financiering/sde](https://www.rvo.nl/subsidies-financiering/sde)

---

## MOOI 2026 (för FoU-projekt)

**MOOI-programmet** (Missiegedreven Onderzoek, Ontwikkeling och Innovatie) från RVO stöder fleråriga samarbeten för innovativa energilösningar. Relevant för organisationer som vill undersöka hur laddinfrastruktur vid kulturella platser kan bidra till nätverkslösningar.

- Minsta bidragsberättigade kostnad: 2 miljoner euro
- Minst 3 partners i konsortiet
- Mer information: [rvo.nl/subsidies-financiering/mooi](https://www.rvo.nl/subsidies-financiering/mooi)

---

## Provins- och kommunbidrag

Många provinser och kommuner har tilläggsbidrag för laddinfrastruktur. Dessa är inte centraliserade — kontrollera:

- Webbplatsen för din provins (sök på "bidrag laddstolpe" eller "eltransport")
- Din kommun (vissa kommuner har specifika regler för samhällsorganisationer)
- [subsidiewijzer.nl](https://www.subsidiewijzer.nl) för en översikt per region

---

## Praktiska tips

1. **Kombinera** — SPRILA och SDE++ kan kombineras i vissa fall. Fråga din revisor eller en bidragsrådgivare.
2. **Ansök före investering** — detta gäller för nästan alla program. Underskriv inte installationsavtalet före ansökan har skickats in.
3. **Spara alla fakturor** — bidragsredovisning kräver detaljerade fakturor för hårdvara, installation och nätverk.
4. **RVO-rådgivningstelefon** — RVO erbjuder gratis rådgivning via 088 042 42 42 och ett onlineprojektidéformulär för kostnadsfri rådgivning.
