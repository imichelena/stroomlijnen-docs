# Guide de localisation

Ce guide décrit ce que vous trouverez sur un site de charge Stroomlijnen typique et comment vous vous y repérez.

## Arrivée sur un site

### Signalisation
Observez les panneaux bleus Stroomlijnen à l'entrée. Les emplacements de charge pour véhicules électriques sont marqués de :
- Marquages au sol (lignes ou symboles électriques peints en bleu)
- Panneaux d'emplacement (correspondant aux ID EVSE dans l'application)
- Flèches de direction pour les emplacements de passage

### Stationnement
- **Emplacements pour camions** sont clairement séparés des emplacements pour voitures particulières
- Disposition de passage où cela est possible — pas besoin de reculer
- Si le site dispose d'une barrière ou d'un portail, utilisez votre badge RFID ou l'application pour y accéder

## Équipement de charge

### Chargeurs rapides DC
Nos chargeurs principaux pour les véhicules utilitaires :
- **Puissance :** 150 kW – 400 kW par connecteur
- **Connecteur :** CCS Combo 2 (norme européenne)
- **Câble :** Refroidi par liquide, portée de 5 m ou plus
- **Affichage :** Écran tactile avec statut de session, puissance, énergie, SoC

### Comment se connecter

1. **Stationnez** dans l'emplacement EV désigné, côté conducteur vers le chargeur
2. **Ouvrez** la trappe de charge CCS du véhicule
3. **Sortez** le connecteur CCS du support du chargeur
4. **Insérez** fermement dans la prise CCS du véhicule jusqu'à ce que vous entendiez/ressentiez un clic
5. **Authentifiez** — PnC démarre automatiquement ; pour RFID, touchez votre badge sur le lecteur ; pour l'application, scannez le code QR
6. **Attendez** jusqu'à ce que l'affichage du chargeur indique "Chargement..." avec une puissance ascendante en kW

### Déconnexion

1. **Arrêtez** la session — touchez à nouveau votre badge RFID, appuyez sur Arrêter dans l'application ou utilisez le bouton d'arrêt sur le chargeur
2. **Attendez** jusqu'à ce que le chargeur confirme que la session est terminée et que le connecteur est déverrouillé
3. **Retirez** le connecteur CCS et replacez-le dans son support
4. **Fermez** la trappe de charge du véhicule
5. **Quittez** l'emplacement pour libérer la place aux autres véhicules

:::caution
N'forcez jamais le connecteur CCS pendant qu'une session est active. Le connecteur se verrouille pendant la charge pour des raisons de sécurité. Arrêtez toujours la session avant.
:::

## Informations de sécurité

- **Arrêt d'urgence** — Bouton rouge sur chaque chargeur, coupe immédiatement l'alimentation électrique
- **Extincteur** — Présent sur chaque site, adapté aux incendies électriques
- **Numéro d'alarme** — Indiqué sur chaque chargeur, ainsi que le numéro standard 112
- **Interdiction de fumer** — La zone de charge est entièrement non fumeurs
- **Restez dans le véhicule ou la salle d'attente** pendant les orages

### Sécurité des câbles
- N'utilisez pas un câble endommagé — signalez-le via l'application ou appelez le support
- Gardez la zone de charge libre de tout obstacle
- Ne roulez pas sur les câbles de charge

## Commodités pour les conducteurs

Les commodités varient selon le type de site :

### Sites de théâtre
- Café ou restaurant souvent présents sur le site ou à proximité
- WiFi public disponible sur la plupart des sites de théâtre
- Toilettes publiques pendant les heures d'ouverture du théâtre

### Plates-formes logistiques
- Salles de repos pour conducteurs avec sièges
- Toilettes
- Distributeurs ou restaurants à proximité

### Tous les sites
- WiFi gratuit (réseau : "Stroomlijnen-Guest")
- Passage couvert lorsque possible
- Éclairage suffisant 24/7

## Signaler des problèmes

Si quelque chose ne va pas sur un site :
- **Problème de chargeur** — Signalez via l'application (Aide → Signaler un problème) ou appelez le numéro de support sur le chargeur
- **Problème de sécurité** — Utilisez le bouton d'arrêt d'urgence si cela est urgent, puis appelez le support
- **Propreté/accès** — Signalez via l'application
- **Suggestion d'amélioration** — Envoyez un e-mail à [feedback@stroomlijnen.nl](mailto:feedback@stroomlijnen.nl)
