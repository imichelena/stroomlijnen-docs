# Modèle de revenu et tarifs

En tant que propriétaire d'un site, vous gagnez de l'argent pour chaque kWh fourni via votre borne de recharge. Il existe trois formes de contrats courantes — chacune avec ses avantages et inconvénients.

## Les trois modèles

### 1. Revenu passif (le plus choisi)

Le CPO gère tout. Vous recevez une rémunération fixe par kWh fourni.

| Caractéristique | Détails |
|---|---|
| Revenu | €0,05 – €0,12 par kWh |
| Coût d'exploitation | Aucun — le CPO gère tout |
| Investissement | Aucun (matériel fourni par le CPO ou via SPRILA) |
| Risque | Minime |

**Exemple de calcul :** 200 sessions par an, 600 kWh par session, €0,10/kWh = **€12.000 par an**.

---

### 2. Exploitation propre

Vous gérez vous-même les tarifs et conservez une marge plus importante. Plus de travail, plus de revenu.

| Caractéristique | Détails |
|---|---|
| Revenu | €0,10 – €0,25 par kWh |
| Coût d'exploitation | Modéré — gestion des tarifs, contact avec les clients |
| Investissement | Matériel (en partie via SPRILA) |
| Risque | Plus élevé (vous êtes responsable de l'exploitation) |

---

### 3. Location de capacité

Vous louez votre connexion à un CPO pour un montant mensuel fixe, indépendamment de l'utilisation.

| Caractéristique | Détails |
|---|---|
| Revenu | €200 – €600 par mois par borne de recharge |
| Coût d'exploitation | Aucun |
| Investissement | Aucun |
| Risque | Aucun — montant fixe, indépendamment de l'utilisation |

---

## Comment fonctionne le paiement

Pour le modèle de revenu passif :

1. Chaque session de recharge est automatiquement mesurée et enregistrée
2. À la fin du mois, le CPO calcule votre part
3. Vous recevez un résumé via votre tableau de bord et un paiement sur votre compte
4. Aucune action manuelle n'est requise — tout se déroule automatiquement

:::note Tableau de bord
Via votre tableau de bord de propriétaire, vous voyez en temps réel combien d'énergie a été chargée, par combien de sessions, et quel est votre revenu prévu pour le mois en cours.
:::

## Ce que vous payez — et ce que vous ne payez pas

| Poste | Payez-vous cela ? |
|---|---|
| Électricité (kWh) pour la session de recharge | **Non** — est facturé à l'utilisateur |
| Matériel et installation | **Non** (via SPRILA ou CPO) |
| Maintenance et réparations | **Non** — est couvert par le contrat CPO |
| Coûts de réseau (abonnement de raccordement) | **Oui** — mais vous payez déjà cela |
| Éventuelle extension du réseau | **Non** — sauf si votre raccordement est trop petit (rare pour les théâtres) |

## SPRILA — détails de la subvention

Le **régime SPRILA** (RVO) subventionne l'achat et l'installation d'infrastructures de recharge publiques pour le transport lourd.

- **Pour qui :** propriétaires de sites qui permettent la recharge pour les camions et les bus
- **Ce qui est remboursé :** matériel (borne de recharge) + coûts d'installation
- **Condition :** demande avant investissement
- **Demande via :** [rvo.nl/subsidies-financiering/sprila](https://www.rvo.nl/subsidies-financiering/sprila)

:::tip
Stroomlijnen vous accompagne dans la demande de subvention SPRILA dans le cadre du package d'installation.
:::
