# Ladeetikette

Stroomlijnen-Ladegeräte sind gemeinsam genutzte Einrichtungen. Durch Beachtung einiger einfacher Umgangsformen bleibt die Erfahrung für jeden angenehm.

## Die Goldenen Regeln

### 1. Blockieren Sie den Ladestandort Nicht
Sobald Ihr Fahrzeug ausreichend geladen ist, entfernen Sie es. Andere Fahrzeuge warten möglicherweise. Laden Sie nachts, das ist in Ordnung — die Standorte sind dafür konzipiert. Seien Sie jedoch während der Spitzenzeiten aufmerksam.

### 2. Trennen Sie die Verbindung, Wenn Sie Fertig Sind
Wenn Ihre Sitzung abgeschlossen ist (Ziel-SoC erreicht oder Sie müssen abreisen):
1. Beenden Sie die Sitzung
2. Hängen Sie das Kabel ordentlich zurück in den Halter
3. Fahren Sie Ihr Fahrzeug aus dem Ladeplatz

### 3. Ein Fahrzeug Pro Ladeplatz
Parken Sie nicht mehrere Fahrzeuge auf einem Ladeplatz, auch nicht, wenn nur eines lädt. Jeder Platz ist für ein Fahrzeug konzipiert.

### 4. Trennen Sie Andere Nicht Ab
Trennen Sie niemals die Ladekabel eines anderen Fahrzeugs. Wenn Sie einen Ladestandort benötigen und alle besetzt sind, warten Sie oder verwenden Sie die App, um zu sehen, wann eine Sitzung voraussichtlich endet.

### 5. Halten Sie Es Sauber
- Lassen Sie keinen Abfall im Ladebereich zurück
- Melden Sie verschüttete Flüssigkeiten oder Gefahren
- Hängen Sie Kabel zurück in ihre Halter — lassen Sie sie nicht auf dem Boden liegen

## Für Flottenfahrer

### Kommunizieren Sie Mit Der Disposition
Wenn Sie längere Zeit an einem Ladestandort bleiben, informieren Sie die Disposition, damit sie andere Fahrzeuge bei Bedarf zu alternativen Standorten umleiten kann.

### Melden Sie Probleme
Wenn Sie einen defekten Ladestandort, eine schmutzige Location oder ein Sicherheitsproblem feststellen — melden Sie es. Ihre Rückmeldung hilft uns, das Netzwerk für jeden zu unterhalten.

### Respektieren Sie Den Standort
Auf Theaterstandorten sind Sie Gast auf fremdem Gelände. Seien Sie respektvoll gegenüber Theaterpersonal, Besuchern und der Umgebung. Der Ruf von Stroomlijnen hängt von guten Beziehungen zu den Standortbesitzern ab.

## Spitzenzeiten

Unsere verkehrsreichsten Zeiten sind in der Regel:
- **Morgen: 06:00–09:00** — Flottenfahrzeuge laden vor dem Abfahren
- **Abend: 18:00–22:00** — Fahrzeuge kehren von ihren Routen zurück

Wenn Sie das Laden außerhalb dieser Zeiten planen können, helfen Sie, die Belastung zu reduzieren und profitieren möglicherweise von niedrigeren Stromtarifen.
