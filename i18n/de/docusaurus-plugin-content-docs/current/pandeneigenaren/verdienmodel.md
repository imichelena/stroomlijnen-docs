# Ertragsmodell und Tarife

Als Immobilieneigentümer verdienen Sie an jedem kWh, der über Ihre Ladestation geliefert wird. Es gibt drei gängige Vertragsformen — jede mit eigenen Vor- und Nachteilen.

## Die drei Modelle

### 1. Passives Einkommen (meist gewählt)

Die CPO regelt alles. Sie erhalten eine feste Vergütung pro gelieferter kWh.

| Merkmal | Details |
|---|---|
| Ertrag | €0,05 – €0,12 pro kWh |
| Betriebskosten | Keine — CPO verwaltet vollständig |
| Investition | Keine (Hardware von CPO oder über SPRILA) |
| Risiko | Minimales |

**Berechnungsbeispiel:** 200 Sitzungen pro Jahr, 600 kWh pro Sitzung, €0,10/kWh = **€12.000 pro Jahr**.

---

### 2. Eigenbetrieb

Sie verwalten selbst die Tarife und halten eine größere Marge. Mehr Arbeit, mehr Ertrag.

| Merkmal | Details |
|---|---|
| Ertrag | €0,10 – €0,25 pro kWh |
| Betriebskosten | Mittel — Tarifverwaltung, Kundenkontakt |
| Investition | Hardware (teilweise über SPRILA) |
| Risiko | Höheres (Sie sind für den Betrieb verantwortlich) |

---

### 3. Kapazitätsvermietung

Sie vermieten Ihre Anschlussmöglichkeit an eine CPO für ein festes monatliches Entgelt, unabhängig von der Nutzung.

| Merkmal | Details |
|---|---|
| Ertrag | €200 – €600 pro Monat pro Ladestation |
| Betriebskosten | Keine |
| Investition | Keine |
| Risiko | Keines — festes Entgelt, unabhängig von der Nutzung |

---

## Wie die Auszahlung funktioniert

Beim passiven Einkommensmodell:

1. Jede Ladesitzung wird automatisch gemessen und registriert
2. Am Ende des Monats berechnet die CPO Ihren Anteil
3. Sie erhalten eine Übersicht über Ihr Dashboard und eine Auszahlung auf Ihrem Konto
4. Keine manuelle Aktion erforderlich — alles läuft automatisch

:::note Dashboard
Über Ihr Eigentümerdashboard sehen Sie in Echtzeit, wie viel geladen wurde, durch wie viele Sitzungen und was Ihr erwarteter Ertrag für den laufenden Monat ist.
:::

## Was Sie selbst bezahlen — und was nicht

| Posten | Zahlen Sie dies? |
|---|---|
| Strom (kWh) für die Ladesitzung | **Nein** — wird an den Nutzer weiterberechnet |
| Hardware und Installation | **Nein** (über SPRILA oder CPO) |
| Wartung und Störungen | **Nein** — fällt unter CPO-Vertrag |
| Netzkosten (Grundpreis Anschluss) | **Ja** — aber dies zahlen Sie ohnehin bereits |
| Eventuelle Netzerweiterung | **Nein** — nur wenn Ihre Anschlussmöglichkeit zu klein ist (selten bei Theatern) |

## SPRILA — Subsidien-details

Die **SPRILA-Regelung** (RVO) subventioniert den Kauf und die Installation von öffentlich zugänglicher Ladeinfrastruktur für schweren Transport.

- **Für wen:** Eigentümer von Standorten, die das Laden für LKW/Busse ermöglichen
- **Was wird erstattet:** Hardware (Ladestation) + Installationskosten
- **Voraussetzung:** Antrag vor Investition stellen
- **Anträge über:** [rvo.nl/subsidies-financiering/sprila](https://www.rvo.nl/subsidies-financiering/sprila)

:::tip
Stroomlijnen unterstützt Sie bei der SPRILA-Antragstellung als Teil des Installationspakets.
:::
